📌 備忘（2026-11-08 更新）z01 新聞脈動：雲端主爬＋外部定時觸發＋本機每小時備援
  • 原因：GitHub 自己的排程實測被節流（約 4~6 小時才跑一次，皆成功），造成熱度圖灰底斷層。
  • 雲端：cron-job.org 每小時整點呼叫 GitHub workflow_dispatch；GitHub 自身排程（第 17 分）保留當備援。
  • 本機：Windows 排程 vault_z01_hourly_local 每小時第 47 分執行 run_hourly_local.bat（先 git pull 同步雲端 feed\，再爬取）。
  • 頁面橫幅：最新一格 >7 小時未更新才顯示「雲端爬蟲疑似停擺」，先查 GitHub Actions 與 cron-job.org 的 HISTORY。
  • 給 agents：feed\ 可能被雲端與本機兩邊寫入，不要手動改 feed\；排程停用請封存不刪。
  • 踩雷（2026-11-08）：任何程式改寫 feed\latest_frame.js 時，變數名必須是 window.A23_FEED；寫成 Z01_LATEST_FRAME 會讓頁面顯示 OFFLINE（無資料）。已修 translate_titles.py。
