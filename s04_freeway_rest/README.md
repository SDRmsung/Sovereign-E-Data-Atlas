# ⛽ `s04_freeway_rest` — (傳) 國道服務區滯留

> **一句話反差副標**：凌晨五點以為沒車，服務區已紫爆  
> **時間顆粒度**：歷史回放：VD 1 分鐘／M03A·M04A 5 分鐘 

## 1. 受眾與價值主張

- **主軌：歷史回放資料敘事**：受眾＝連假後的大眾與媒體、交通研究者；價值＝回看連假 96 小時服務區何時何處被滿載、主線如何被拖慢。
- **副軌：即時參考**：同一管線若接上即時 API，可作行前參考；只顯示服務區車位與上游 VD 速率，不推估滯留時間，也不下「別去哪個服務區」的結論。
- **不做（Out of Scope）**：個體滯留時間、即時導流與避塞導航、高公局調度建議（無 live 證據前不宣稱）。

## 2. 指標與代理變數

- **承認限制**：M03A/M04A 為 5 分鐘聚合資料，無個體識別，且兩門架之間含交流道，無法分離進入服務區的淨車流；因此**不輸出「平均滯留時間」**，也不套 Little's Law（非穩態）。
- **溢流警戒指數（代理）**＝服務區車位「滿載持續時間」＋ 上游最近 VD 外側車道「速率 <20 km/h 的延時與佔有率」；滿位後由指數接手，不靠可用率。20 km/h 為暫定門檻，須以歷史資料校準。
- **M03A 不用於推算進站量**；僅作主線背景流量。

## 3. 資料源與限制

- 交通部 TDX：國道服務區停車位 API（更新頻率以實測為準）
- 高公局 VD：1 分鐘；M03A/M04A：5 分鐘（**分源標註，不得合稱「1–5 分鐘」**）
- **限制**：車位資料滿位即飽和，看不到引道溢流，故需上游 VD 外側車道代理；缺漏值以灰色標示、不內插。

## 4. 視覺映射規格（`deck.gl`；底圖依敘事選用，不強制 DEM）

- 主線：VD 速率 → 顏色與粒子速度；以路段區間為單位沿線內插成動畫（聚合資料，不宣稱逐車軌跡，故用 PathLayer 而非 TripsLayer）。
- 服務區：滿載時長 → 光球半徑；溢流警戒指數 → 紫紅波紋頻率。
- 底圖**不使用 20m DEM**（與服務區敘事無關）。
- 敘事鏈：微觀（要不要拐進清水）→ 轉換（服務區持續滿載、上游外側車道減速延時累積）→ 巨觀（溢流倒灌主線，國一國三光帶轉紅）。

## 5. 五力評估與風險（資料力 + 視覺力 + 故事力 + 共鳴力 + 應用力）

> 只寫理由與扣分點，不評分；扣分基準見 [[35-Areas/A23_Data_Atlas/00_notes/n00_story_scoring_gate|n00. 評分門檻]]。

- **資料力**：官方資料齊但缺個體軌跡；扣分：滯留時間不可得，只能以代理指標呈現，資料力有上限。
- **視覺力**：光帶轉紅加紫紅波紋反差強；扣分：聚合資料非逐車，動畫為路段插值。
- **故事力**：凌晨五點以為沒車，服務區已紫爆；扣分：連假事件依賴，須用歷史資料驗證溢流先於主線變慢。
- **共鳴力**：連假回家必經；扣分：歷史回放不能回答哪個服務區別去，實用性訴求要降調。
- **應用力**：可供連假後檢討服務區容量；扣分：無 live 證據前不宣稱即時導流，不得用於調度。
