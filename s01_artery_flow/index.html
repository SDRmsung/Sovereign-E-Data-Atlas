即時資料流與管線步驟 Pipeline v2.0

STEP 01

免金鑰高公局 OpenAPI 抓取

透過高速公路局免驗證開放資料，每 60 秒輪詢 VD 車速、路段旅行時間與 CMS 即時告警文字。

STEP 02

TDX OAuth2 雙軌備援架構

注入 client_id / secret 自動換取短期 Token，當高公局免金鑰來源超時自動切換至交通部 TDX 標準接口。

STEP 03

零 CORS 靜態 JS 資料幀 (latest_frame.js)

收集器落盤產出 `window.A23_FEED` 變數封裝，前端以 `<script>` 直接載入，本機 file:// 離線開箱即用。

LAYER 01 · DATA INGESTION 1968 OpenAPI + TDX

1. 交通資料擷取：國道免金鑰與 TDX 雙軌

  • 國道免金鑰來源：透過高速公路局免驗證公開端點，零 Token 門檻即時抓取國道 1、3、5 號 VD 站點數據。
  • TDX 雙軌備援機制：配置 OAuth2 自動展期，當免金鑰服務異常時平滑切換至交通部 TDX 權威數據源。
  • 動態流量限速防護：內建指數退避重試與本機快取緩衝，確保長時間爬取零中斷且不觸發遠端 IP 封鎖。
LAYER 02 · FEED PACKAGING Zero-CORS JSONP / JS

2. 前端實時資料封裝：零 CORS 靜態資料幀

  • 零 CORS 協定相容：資料幀輸出為 `feed/latest_frame.js`，將最新路況宣告至全域命名空間。
  • 即時欄位鏡像：同步產出 `feed/latest_frame.json` 供後續 Python 分析或 Grafana/Obsidian 儀表板消費。
  • 原子化狀態快照：包含全路網累積車次、即時車流估算、異常事件陣列與 VD 站點在線健康度。
LAYER 03 · WEBGL ENGINE Mapbox / MapLibre + deck.gl

3. 核心視覺化引擎：Mapbox GL + deck.gl

  • 底層 3D 相機：由 Mapbox GL JS 或開源 MapLibre GL 控制俯仰視角、方位角與暗色地形底圖同步。
  • 上層發光血管：使用 Uber 開源 WebGL 框架 deck.gl 之 PathLayer 與 TripsLayer 動態流動渲染。
  • 動態著色邏輯：WebGL Shader 依即時車流與車速上色（橘色代表壅塞、藍色代表順暢），西部走廊亮點為 VD 投影。
LAYER 04 · COMPOSITING AE / Premiere HUD

4. 影片合成：HUD 數據儀表與衛星雲圖疊加

  • 動態計數 UI：後期合成時鐘、累計車輛跳動計數、國道與快速道路即時在線數與路況警訊。
  • 氣象雲圖融合：於時間軸推進至 17:30 後疊入中央氣象署颱風衛星雲圖半透明圖層。
  • 縮時敘事輸出：將全日 00:04 至 22:33 數據痕跡壓縮為 59 秒高密度縮時影片，呈現真實上路軌跡。
