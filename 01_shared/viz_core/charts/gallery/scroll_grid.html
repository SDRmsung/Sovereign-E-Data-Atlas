05 遮罩展開 クリップパス展開

shape: "inset" 由左至右矩形裁切展開（inset(0 100% 0 0) → inset(0 0 0 0)），適合圖卡與標題帶。
shape: "circle" 從中心點半徑擴散展開（circle(0%) → circle(75%)），適合焦點 KPI 揭露。
shape: "polygon" 多邊形斜角推進展開（polygon(0 0, 0 0, 0 100%, 0 100%) → 全幅），適合敘事轉場。
關鍵參數clipReveal(el, { shape: "inset|circle|polygon" })；進場 threshold: 0.15 觸發一次即 unobserve；緩動 640ms cubic-bezier(.22,1,.36,1)
坑點prefers-reduced-motion: reduce 須直接展開（clip-path: none）；僅在 .fx-js 存在時初始收合，確保無 JS 時內容完整可讀。
